# คู่มือเปิดระบบเซิร์ฟเวอร์ (เวอร์ชัน 2)

ตอนนี้เซิร์ฟเวอร์ (Supabase) เป็นผู้ตัดสินเรื่องต่อไปนี้ทั้งหมด ผู้เล่นแก้ค่าเองในเบราว์เซอร์ไม่ได้

- เหรียญ อัมพร พลังงาน
- ผลสุ่มฟักไข่
- อัปเลเวล วิวัฒนาการ จัดทีม
- รางวัลรายวัน ภารกิจ และต้นอัมพร

ใช้เวลาตั้งค่าประมาณ 5 นาที ทำใน Supabase โปรเจกต์เดิม (`spkzkwksjweszytkgokx`)

## 1. สร้างตารางและฟังก์ชัน

1. เข้า Supabase แล้วเลือกเมนู **SQL Editor** กด **New query**
2. คัดลอกไฟล์ `setup_v2.sql` ทั้งหมดมาวาง แล้วกด **Run**
3. ถ้าขึ้น `Success. No rows returned` แปลว่าเรียบร้อย ถ้ามีข้อความ NOTICE ก็ไม่เป็นไร

รันซ้ำได้ตลอด ข้อมูลผู้เล่นเดิมจะไม่หาย ส่วนตาราง `player_saves` ของเวอร์ชันแรกยังอยู่เหมือนเดิม ไม่ได้ลบ

## 2. เปิดล็อกอินแบบผู้เยี่ยมชม

ผู้เล่นจะเข้าเกมได้ทันทีโดยไม่ต้องสมัคร ระบบจะสร้างบัญชีผู้เยี่ยมชมให้อัตโนมัติ

1. ไปที่ **Authentication → Sign In / Providers**
2. หาหัวข้อ **Allow anonymous sign-ins** แล้วเปิด จากนั้นกด **Save**

## 3. (ไม่บังคับ) ให้ผูกบัญชีผู้เยี่ยมชมกับ Google ได้

ทำขั้นนี้เมื่อเอาเกมขึ้นเว็บจริงแล้ว เช่นบน GitHub Pages

1. **Authentication → Sign In / Providers**: เปิด **Allow manual linking**
2. ตั้งค่า Google ตามคู่มือเดิม (ขั้นที่ 5–6)
3. **Authentication → URL Configuration**: ใส่ลิงก์เกมจริงใน Site URL และ Redirect URLs

## 4. ทดสอบ

1. เปิดเกม แล้วดูจุดเล็ก ๆ ที่มุมรูปโปรไฟล์ซ้ายบน
   - **สีเขียว**: ออนไลน์ เซฟบนเซิร์ฟเวอร์
   - **สีส้ม**: ออฟไลน์ เซฟในเครื่องนี้ (ต่อเซิร์ฟเวอร์ไม่ได้ หรือยังไม่ได้ทำขั้นที่ 1–2)
2. แตะรูปโปรไฟล์เพื่อดูสถานะบัญชี เปลี่ยนชื่อ หรือกดลองเชื่อมต่อใหม่

## กติกาเกมที่อยู่บนเซิร์ฟเวอร์

| เรื่อง | ค่า |
|---|---|
| พลังงาน | สูงสุด 60 ฟื้น 1 หน่วยทุก 3 นาที |
| ต้นอัมพร | ได้ 5 อัมพรทุก 10 นาที |
| ไข่ป่า | 100 เหรียญ · ได้ ★5 อามาเทรุ 2% |
| ไข่ทองคำ | 30 อัมพร · ได้ ★5 8% · ครบ 30 ใบการันตี ★5 |
| ช่องเก็บ | 30 ตัว |
| อัปเลเวล | 60 × เลเวลปัจจุบัน (เหรียญ) |
| วิวัฒนาการ | คาเซะมารุ Lv20 → คาเซะคิริ · 300 เหรียญ |
| รางวัลรายวัน | วนทุก 7 วัน รีเซ็ตเที่ยงคืนเวลาไทย |
| ด่าน 1-1 ถึง 1-3 | ใช้พลังงาน 6 · ต้องเล่นอย่างน้อย 15 วินาที · ชนะได้ 80 / 100 / 150 เหรียญ |

ถ้าจะปรับตัวเลข ให้แก้ในฟังก์ชัน `public._c` ของ `setup_v2.sql` แล้วรันใหม่ และต้องแก้ค่าเดียวกันใน `LOCAL` ของ `net.js` ด้วย เพื่อให้โหมดออฟไลน์ใช้กติกาเดียวกัน

## ความปลอดภัย

- ในหน้าเว็บมีแค่ **Publishable key** ห้ามใส่ Secret key หรือ service_role เด็ดขาด
- ผู้เล่นอ่านได้เฉพาะข้อมูลของตัวเอง เขียนตารางตรง ๆ ไม่ได้ ต้องแก้ผ่านฟังก์ชันที่เซิร์ฟเวอร์ตรวจแล้วเท่านั้น
- ฟังก์ชันที่ขึ้นต้นด้วย `_` เป็นฟังก์ชันภายใน เรียกจากหน้าเว็บไม่ได้
- Supabase จำกัดการสร้างบัญชีผู้เยี่ยมชมไว้ที่ 30 บัญชีต่อชั่วโมงต่อ IP อยู่แล้ว ถ้าเกมมีคนเล่นเยอะ แนะนำให้เปิด CAPTCHA ในเมนู **Authentication → Attack Protection**
